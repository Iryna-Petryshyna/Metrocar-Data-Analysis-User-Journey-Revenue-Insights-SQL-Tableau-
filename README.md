# 🚗 Metrocar Data Analysis – User Journey & Revenue Insights (SQL + Tableau)

## 🎯 Мета проєкту
Навчальний pet-проєкт, створений у межах курсу **Data Analytics**, спрямований на дослідження поведінки користувачів мобільного застосунку Metrocar.  
Мета — проаналізувати шлях користувача від встановлення застосунку до завершення поїздки та дослідити чинники, що впливають на активність і доходи.

## ⚙️ Технічні деталі
- **Інструменти:** PostgreSQL / SQL, Tableau  
- **Формат даних:** кілька зв’язаних таблиць (ride_requests, signups, app_downloads, transactions)  
- **Етапи:**  
  1. Підготовка даних SQL-запитами  
  2. Агрегація ключових метрик (кількість поїздок, користувачі, транзакції, середній час очікування)  
  3. Візуалізація у Tableau  

---

## 📊 Основні інсайти
- Найбільша активність користувачів спостерігається у вечірні години.  
- Найчастіше поїздки здійснюють користувачі середнього віку.  
- Середній час очікування водія — близько **2,5 хвилин**.  
- Доходи зростають у вихідні та святкові дні.  

---

## 💡 Висновки
Дані дозволяють компанії Metrocar:
- оптимізувати графік роботи водіїв у години пік;  
- точніше прогнозувати попит;  
- підвищити утримання користувачів завдяки персоналізованим акціям.
