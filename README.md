# 🚗 Metrocar Data Analysis – User Journey & Revenue Insights (SQL + Tableau)

## 🎯 Мета проєкту
Компанія Metrocar - платформа для виклику авто. Метою її діяльності є покращення користувацького досвіду та збільшення кількості завершених поїздок.
Метою проекту є виявлення основних точок відтоку користувачів на шляху від завантаження додатку до завершення поїздки.
Проаналізовано на яких саме етапах втрачаються користувачі і причини по яким це відбувається. 
Мета — проаналізувати шлях користувача від встановлення застосунку до завершення поїздки та дослідити чинники, що впливають на активність і доходи.

## 📊 Основні інсайти з аналітики Metrocar

- **Користувацька активність:**  
  Загальна кількість користувачів – **6 233**, із них успішно завершено **212 628** поїздок.  
  Середня виручка компанії склала **4,25 млн USD**.

- **Воронка користувача:**  
  Лише близько **25% користувачів**, які завантажили застосунок, доходять до етапу реєстрації,  
  а лише **49%** із тих, хто заплатив, залишають відгук. Це вказує на потенціал покращення користувацького досвіду після поїздки.

- **Активність за часом доби:**  
  Найвищий попит спостерігається у **ранкові (8–9)** та **вечірні години (17–19)** — типові пікові періоди для поїздок на роботу та додому.  
  Ці інтервали мають найбільшу концентрацію запитів незалежно від платформи.

- **Розподіл за віковими групами:**  
  Найактивніші користувачі — вікові категорії **25–34** та **35–44 роки**,  
  які разом формують понад **60% усіх поїздок**. Молодша група (18–24) демонструє нижчу частку використання.

- **Типи платформ:**  
  Найбільше користувачів працюють із **Android**, на другому місці — **iOS**, незначна частка припадає на **web-платформу**.  
  Це вказує на потребу оптимізувати мобільний досвід, особливо для Android-користувачів.

- **Фінансові показники:**  
  Стабільний ріст доходу спостерігається паралельно зі збільшенням кількості успішних поїздок.  
  Частка завершених оплат залишається високою, що підтверджує ефективність платіжного процесу.
