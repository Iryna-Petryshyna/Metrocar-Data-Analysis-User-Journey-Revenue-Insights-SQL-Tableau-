# 🚗 Metrocar Data Analysis – User Journey & Revenue Insights (SQL, Google Spreadsheets, Tableau)

## 🎯 Мета проєкту
Компанія Metrocar - платформа для виклику авто. Метою її діяльності є покращення користувацького досвіду та збільшення кількості завершених поїздок.
Метою проекту є виявлення основних точок відтоку користувачів на шляху від завантаження додатку до завершення поїздки.
Проаналізовано на яких саме етапах втрачаються користувачі і причини по яким це відбувається. 
Мета — проаналізувати шлях користувача від встановлення застосунку до завершення поїздки та дослідити чинники, що впливають на активність і доходи.

## 📊 Основні інсайти з аналітики Metrocar
- 6,2K користувачів, понад 212K успішних поїздок, виручка – 4,25M USD.  
- Найвищий попит у ранкові (8–9) та вечірні години (17–19).  
- Найактивніші користувачі - вікові групи 25–44 роки.  
- Основна платформа - Android, менша частка припадає на iOS і web.  
- Лише 25% користувачів доходять до етапу реєстрації → потенціал покращення UX.  
- Середній рівень оплат і завершених поїздок стабільно високий.
